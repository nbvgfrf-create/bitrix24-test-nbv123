# Bitrix24 XLSX Importer

Импорт данных из `companies (5).xlsx` в Bitrix24 через входящий вебхук.

## Что импортируется

- компании;
- контакты;
- связи контактов с компаниями;
- дистрибьюторы и связи с компаниями;
- тип компании;
- отрасль;
- страна;
- старый ответственный;
- Competitor software;
- License expiration date;
- адреса через реквизиты Bitrix24.

## Запуск в Render

В Environment Variables должен быть задан:

`BITRIX_HOOK`

Значение существующего вебхука менять не требуется.

### Порядок запуска

1. Открыть `/diagnostic.php` и убедиться, что Bitrix24 доступен.
2. Открыть `/xlsx_to_json.php` — создаются очереди и runtime.
3. Открыть `/run.php` — выполняется один рабочий цикл.
4. Повторять `/run.php`, пока очереди не закончатся.
5. `/check.php` показывает результат.

## Важный момент по правам

Подготовка runtime не запрашивает список шаблонов реквизитов и список стран через REST.
Для этой конфигурации используются уже проверенные значения:

- Россия: `COUNTRY_ID=1`, `RU`;
- шаблон реквизита «Организация»: `PRESET_ID=1`.

Это позволяет вебхуку с обычными CRM-правами выполнять импорт без дополнительного административного scope.
