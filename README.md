# Bitrix24 XLSX Import

Простой импорт `companies (5).xlsx` в Bitrix24.

В текущем файле: 2372 строки, 2368 уникальных компаний, 1062 уникальных контакта и 35 уникальных дистрибьюторов.

1. Открой `/run.php`.
2. Нажми `Подготовить`.
3. Нажми `Запустить импорт`. Страница сама запускает worker небольшими циклами.

Импортируются компании и контакты из XLSX. Для компаний заполняются тип, отрасль, страна, старый ответственный, дистрибьютор, Competitor software и License expiration date. Основные контакты связываются с компаниями.

Дистрибьюторы создаются первыми, чтобы их ID можно было записать в поле CRM-связи. Адреса создаются через реквизиты Bitrix24 с типами `Actual`, `Legal`, `Shipping`. Для реквизитов используется Россия (`RU`, ID 1) и шаблон `Организация` (ID 1).

Все новые записи назначаются на пользователя ID 1.

После завершения разработки замени временный вебхук в `config.php`.

Для нового импорта сначала удали `data/queues/*.json`.
