# Bitrix24 XLSX Import

Простой импорт `companies (5).xlsx` в Bitrix24.

В исходном файле: 2372 строки, 2368 уникальных компаний, 1062 уникальных контакта и 35 дистрибьюторов.

Импорт идёт по очереди:

1. Дистрибьюторы.
2. Контакты.
3. Компании и связи с контактами/дистрибьюторами.
4. Реквизиты и адреса компаний.

Для компаний заполняются:

- Тип
- Отрасль
- Страна
- Старый ответственный
- Дистрибьютор
- Competitor software
- License expiration date
- Адреса Actual / Legal / Shipping

Все созданные записи назначаются на пользователя ID 1.

## Запуск

Открой `/run.php`.

Нажми `Подготовить`, затем `Запустить импорт`.

Worker обрабатывает записи обычными REST-запросами, небольшими порциями. Это намеренно простая схема: она использует ту же модель вызовов, что и предыдущая рабочая версия.

Если во время старой версии какие-то записи уже были помечены как `failed`, новая версия автоматически попробует их ещё раз. Удалять `data/queues` после неудачного worker не требуется.

Для нового файла после его замены нужно нажать `Подготовить`. При новом деплое Render каталог `data` может быть пустым.

Вебхук сейчас указан в `config.php` только для разработки. После окончания работы его нужно заменить.
