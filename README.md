# Bitrix24 XLSX Import v2

Проект импортирует данные из `companies (5).xlsx` в Bitrix24 по этапам: дистрибьюторы → контакты → компании → адреса.

## Диагностика

Перед подготовкой очередей открой:

`/diagnostic.php`

Эта страница не требует `runtime.json` и показывает, какие пользовательские поля компаний, статусы, типы адресов, страны и шаблоны реквизитов реально возвращает Bitrix24.

Если `xlsx_to_json.php` пишет ошибку о том, что не найдено поле `UF_CRM_IMPORT_...`, сначала открой `/diagnostic.php` и сверяй `FIELD_NAME`.

## Подготовка импорта

После того как коды полей в `config.php` проверены:

`/xlsx_to_json.php`

Скрипт создаёт:

- `queues/distributors.json`
- `queues/contacts.json`
- `queues/companies.json`
- `runtime.json`

## Запуск

Открой:

`/run.php`

Страница запускает один worker сразу, затем повторяет запуск каждые 2 минуты.

`worker.php` продолжает импорт с сохранённых очередей и отдельно обрабатывает адреса.

## Проверка

`/check.php`

Показывает состояние очередей и проверяет несколько готовых компаний непосредственно через Bitrix24.

## Render

Для Render предусмотрен Dockerfile. На Render рекомендуется задать секрет Bitrix webhook в Environment Variable:

`BITRIX_HOOK`
