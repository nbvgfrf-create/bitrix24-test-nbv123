# Bitrix24 XLSX Import

Импорт `companies (5).xlsx` в Bitrix24.

Из файла: 2372 строки, 2368 уникальных компаний, 1062 уникальных контакта и 35 дистрибьюторов.

Поля компаний:
- `Тип` → стандартное поле типа компании (`typeId`)
- `Отрасль` → стандартное поле отрасли (`industry`)
- `Страна` → `UF_CRM_COUNTRY_IMPORT`
- `Ответственный` → `UF_CRM_OLD_RESPONSIBLE`
- `Дистрибьютор` → `UF_CRM_DISTRIBUTOR` (CRM binding, `CO_ID`)
- `Competitor software` → `UF_CRM_COMPETITOR_SOFTWARE`
- `License expiration date` → `UF_CRM_LICENSE_EXPIRATION_DATE`
- `Address` + `Address type` → реквизит компании и адрес реквизита

Все создаваемые записи получают ответственного ID 1 (Тимофей Жмаев).

## Запуск

1. Открой `/run.php`.
2. Нажми `Подготовить`.
3. Нажми `Запустить импорт`.

После исправления проекта уже созданные компании не нужно удалять. Кнопка `Исправить уже созданные компании` повторно записывает в существующие компании тип, отрасль, старого ответственного, страну, дистрибьюторов и остальные импортируемые поля.

Если очереди были потеряны после нового деплоя, снова нажми `Подготовить`, а затем `Исправить уже созданные компании`: скрипт найдёт существующие компании по названию и обновит их, не создавая копии.
