# Bitrix24 XLSX Import v2

Версия рассчитана на повторный импорт после удаления созданных компаний и контактов.

## Что изменилось

- `setup.php` больше не нужен.
- `xlsx_to_json.php` сам подготавливает `runtime.json` и проверяет, что пользовательские поля и стандартные значения существуют.
- Страна берётся из колонки `Страна`, а не задаётся одной константой.
- Старый ответственный берётся из `Ответственный` и сохраняется в `UF_CRM_IMPORT_OLD_RESPONSIBLE`.
- Адреса сохраняются отдельно в очереди и импортируются отдельным этапом после создания компаний.
- Для адресов создаётся address-only requisite и затем `crm.address.add`.
- Дистрибьюторы создаются до компаний, поэтому CRM-связи `Дистрибьютор` получают реальные ID.
- Контакты создаются до компаний; при создании компании передаются `contactIds`.
- Worker использует Bitrix batch, до 50 подзапросов за один HTTP-запрос; фактический размер batch настраивается через `BATCH_SIZE`.
- Ошибки отдельных элементов не ломают весь batch: элемент остаётся `pending` до `MAX_ATTEMPTS`, после чего получает `failed`.
- `check.php` показывает состояние очередей и проверяет сохранение страны и старого ответственного на 5 готовых компаниях.

## Порядок запуска

1. В Bitrix24 удалить импортированные компании и контакты.
2. Пользовательские поля не удалять.
3. Заменить файлы проекта этой версией и проверить `BITRIX_HOOK` в `config.php`.
4. Удалить старые `queues/*.json` и `runtime.json`.
5. Открыть `xlsx_to_json.php` один раз.
6. После сообщения `Готово` открыть `run.php`.
7. После окончания открыть `check.php`.

`run.php` запускает worker сразу и повторяет старт каждые 2 минуты от начала предыдущего запуска.

## Важно

В `config.php` должны быть именно существующие имена полей:

- `UF_CRM_IMPORT_COUNTRY`
- `UF_CRM_IMPORT_OLD_RESPONSIBLE`
- `UF_CRM_IMPORT_DISTRIBUTOR`
- `UF_CRM_IMPORT_COMPETITOR_SOFTWARE`
- `UF_CRM_IMPORT_LICENSE_EXPIRATION`

Если поле или значение справочника отсутствует, подготовка остановится до начала импорта. Это сделано специально, чтобы данные не «тихо» потерялись.
